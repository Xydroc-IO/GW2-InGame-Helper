Prerequisites

  • Guild Wars 2 with Raidcore Nexus and GW2-InGame-Helper
  • ArcDPS recording combat logs
  • Network the first time EI downloads (and for dps.report uploads)

Default log folder (Windows path; under Proton this is inside the prefix):

Documents\Guild Wars 2\addons\arcdps\arcdps.cbtlogs

On Proton that usually maps under …/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/Documents/Guild Wars 2/addons/arcdps/arcdps.cbtlogs

The pad uses two optional pieces outside the game client:

  1. Elite Insights CLI — auto-downloaded into addons/GW2-InGame-Helper/ei/
  2. .NET 8 Desktop Runtime (x64) — in the Windows environment that runs GW2 (native or Proton prefix)

Elite Insights is MIT software by baaron4 / GW2-Elite-Insights-Parser. The addon downloads official GW2EICLI.zip and verifies SHA-256 — binaries are not baked into the DLL.

Open the Pad

  1. Open the In-Game Helper window.
  2. Click DPS Logs on the pad row (or ⋯ → Show DPS Logs, or Nexus Options → Show DPS Logs).
  3. Confirm the log folder path looks correct (edit if you moved ArcDPS logs).

Elite Insights (Automatic)

  1. In DPS Logs, click Install / Update EI (also runs when the pad opens if EI is missing).
  2. The addon prefers a local GW2EICLI.zip next to the DLL / in the addon folder, or downloads the latest from GitHub releases, verifies SHA-256, extracts to addons/GW2-InGame-Helper/ei/, and fills the CLI path.
  3. Status should show Elite Insights ready (version stamp in ei/ei.ver).

You can still paste a custom path to GuildWars2EliteInsights-CLI.exe if you maintain your own install.

.NET 8 Desktop Runtime

EI’s CLI needs the Windows .NET 8 Desktop Runtime (x64).

  • Download: .NET 8 Desktop Runtime (x64)
  • Direct installer: aka.ms/dotnet/8.0/windowsdesktop-runtime-win-x64.exe

In the pad, Install .NET 8 Runtime opens that link. Recheck .NET rescans after you finish installing.

Windows (native)

Run windowsdesktop-runtime-*-win-x64.exe, finish the wizard, then Recheck .NET in DPS Logs. Use Parse pending or Load report meta as needed.

Linux / Steam Deck

Install into the GW2 Wine prefix via Protontricks — see the Proton section below. Distro dotnet packages will not work.

Linux / Proton — Install .NET into the Prefix

Wine maps your Linux disk as Z:. Run the Windows installer inside the GW2 prefix.

A. Download on Linux

  1. Download the Windows Desktop runtime x64 installer from dotnet.microsoft.com (e.g. windowsdesktop-runtime-8.0.x-win-x64.exe).
  2. Save it to ~/Downloads.

B. Open the GW2 prefix

  1. Open Protontricks.
  2. Select Guild Wars 2 → OK.
  3. Select the default wineprefix → OK.
  4. Run explorer → OK.

C. Run via Z:

  1. In Explorer: My Computer → (Z:) → home → your username → Downloads.
  2. Double-click the .exe and complete Install.
  3. .NET now lives on that prefix’s C: drive.

D. Confirm in the addon

  1. Fully restart Guild Wars 2.
  2. DPS Logs → Recheck .NET — the yellow warning should clear.

Install Protontricks from your distro or Flatpak (com.github.Matoking.protontricks) if needed. Always pick Guild Wars 2 — another game’s prefix will not help.

Troubleshooting

.NET not detected

Windows: install Desktop x64, then Recheck. Proton: you installed on Linux or the wrong prefix — use Protontricks + Z: for Guild Wars 2 only. Fully quit GW2 after installing.

EI install / parse fails

Install / Update EI again. Confirm ei/GuildWars2EliteInsights-CLI.exe exists. Fix .NET first. Check the Detail pane for a red parse error.

Filenames but no DPS

Use Load report meta / Rescan, or Parse pending with EI + .NET. Confirm the folder has real .zevtc / .evtc files.

Install .NET opens a browser only

The browser saves the .exe to Linux Downloads. You must still run it through Protontricks → Explorer → Z: so it installs into the prefix.

Privacy

  • Combat logs and dps.report links can contain account names and guild tags — keep them local unless you upload.
  • Do not share your optional dps.report user token.
