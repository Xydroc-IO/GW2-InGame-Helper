API Key Setup

Create a read-only ArenaNet API key and paste it into the addon so Wallet, Vault, Account, and TP delivery can load your data.

Create a Key on account.arena.net

Official ArenaNet applications page — free, read-only.

  1. Open account.arena.net/applications and sign in with your Guild Wars 2 account.
  2. Click New Key (or create a new application / API key).
  3. Give it a clear name, e.g. In-Game Helper.
  4. Enable the scopes listed below (tick every box in that list for full addon features).
  5. Create / save the key, then copy the long key string.

Treat the key like a password. Anyone with it can read the account data those scopes allow. You can revoke or recreate keys anytime on the same page.

Required Scopes

Enable these on the key for GW2-InGame-Helper.

ScopeUsed for
accountBase account identity — needed for almost every personal API call
walletWallet pad (currencies)
inventoriesBank, material storage, shared inventory, bags / stash views
charactersCharacter roster and per-toon bags
progressionWizard’s Vault / Dailies live progress; world-event claim marks
unlocksLegendary Armory unlocks (Account → Progress)
tradingpostTrading Post delivery box (items waiting to claim)

Recommended: enable all of the scopes above on one key. Item lookup and public TP prices work without a key; personal Vault, wallet, mats, unlocks, and delivery need these scopes.

Add the Key to the Addon

  1. Open Nexus Options → find GW2-InGame-Helper (or open the helper Options panel).
  2. Find GW2 API key (Live panels).
  3. Paste the key into the field (it is masked like a password).
  4. The key is saved to this addon’s settings.ini. Reload Live / Account tabs if they were already open.

Shortcuts from Options:

  • Create key on account.arena.net — opens the applications page in your browser
  • Clear API key — removes the saved key from the addon

You can also see key status from the Account pad when personal data fails to load (missing key or missing scopes).

What Uses the Key

Wallet

Currencies — needs account + wallet (+ inventories / characters for stash & bags).

Vault / Dailies

Live Wizard’s Vault — account + progression.

Account / Progress

Mats, legendaries, roster — inventories, unlocks, characters.

TP delivery

Delivery box — tradingpost. Watchlist prices are public (no key).

If a panel says it needs a scope, edit the key on arena.net (or create a new one with the missing ticks) and paste it again.

Privacy

  • The key is stored only in this addon’s settings.ini.
  • It is never shared, never put in QR codes, and never uploaded with combat logs.
  • Use a read-only key with only the scopes you need — do not share screenshots that show the full key string.
