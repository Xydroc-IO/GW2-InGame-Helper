GW2 In-Game Helper

Your Game Helper inside Guild Wars 2 — Browse, Account, Pathing, Economy, and more, without alt-tabbing.

Version 2.2.3.12 Signature HELP · 0x48454C50 Author xydroc License MIT Requires Raidcore Nexus + GW2 Updates GitHub Releases

One DLL. A private Chromium overlay (CEF 150) for Wiki, builds, guides, and cheat sheets — plus side-rail tools for account data, world pathing, trading, map completion, farming, and DPS logs. No game memory reads. Official Nexus APIs and MumbleLink only.

Install: copy GW2-InGame-Helper.dll into <Guild Wars 2>/addons/ only. First open downloads the CEF runtime once into addons/GW2-InGame-Helper/cef/. Open with Ctrl+Shift+H or the QuickAccess icon. Fully restart Guild Wars 2 after updating.

What you get

Four pillars — open anything from the left side rail.

Browse

2,720 catalog entries — Wiki, builds, guides, tools, offline cheat sheets, and community Discords — in up to 8 tabs with Find, Favorites, and Open Ext for system-browser logins.

Account & Economy

Official API pads for progress, unlocks, vault, wallet/stash, TP watchlist, item lookup, crafting plans, Flip Finder, and charts. Read-only commerce — no trading automation.

Pathing & World

Curated Tekkit, Lady Elyssa, and Hero packs (plus your .taco files), compass, in-world GPS ribbons, Trail Tools for authors, and a floating GPS arrow.

Progress tools

Completion checklist + Atlas routes, Farming runs with live map nodes, Instances journal, World Events, Notes/waypoints, and DPS Logs via Elite Insights.

Side rail

  • Browse · Ledger · Sheets · API Check — catalog hub, Legendary Ledger, cheat sheets, endpoint probe
  • Compass · Vault · Events · Instances · Economy · Farming
  • Pathing · Trail Tools · Completion · Notes · DPS Logs · Account · Settings

Rebind panel chords under Settings → Keybinds. Helper open stays on Nexus / QuickAccess (Ctrl+Shift+H).

Platform notes

  • Windows / Wine / Proton — same DLL; CEF extracts under the addon folder.
  • Safe with multiple clients — PID-scoped IPC; no Present hooks; no bin64 CEF writes.
  • API key — optional, local only; see Browse → Help → API Key Setup.
  • DPS Logs — needs Elite Insights (.NET 8); see Browse → Help → DPS Log Setup.
