GW2 In-Game Helper

In-game browser for Guild Wars 2 — Wiki, MetaBattle, Guildjen, and more.

Version 2.0.2.8 · Signature 0x48454C50 · Author xydroc · License MIT · Requires Raidcore Nexus + Guild Wars 2 · Updates GitHub Releases

GW2 In-Game Helper opens useful Guild Wars 2 websites and community Discord invites inside the game — 2,662 Browse entries covering Wiki, builds, tools, guides, farming, and more.

Players install a single DLL. No memory reads; official Nexus APIs only. Chromium is a private CEF 150 runtime (downloaded once into the addon folder).

Install: copy GW2-InGame-Helper.dll to <GW2>/addons/ only. Runtime files extract into <GW2>/addons/GW2-InGame-Helper/ (including private cef/ on first open). Open with Ctrl+Shift+H or the QuickAccess icon.

Features

Catalog size: 2,662 Browse entries — 2,271 Wiki pages · 294 guides · 23 offline cheat sheets · 16 build hubs · 19 Discord invites · plus Tools (incl. GW2.app), Search, and Discord.
  • In-game browser — full CEF pages inside Guild Wars 2 (private CEF 150 under addons/.../cef/)
  • Browse panel — search + categories; collapsible sections; clipped large Wiki lists
  • Compact toolbar — Browse · Back / Forward / Home / Reload · Find in page · Web · ... menu (Find / Copy URL / Open Ext)
  • GW2-themed chrome — gold / bronze panels, gold tabs, muted status line
  • Tabs — up to 8 live pages; pin; reopen closed; live titles from the page; persisted across sessions
  • Tab hotkeys — Ctrl+T new tab · Ctrl+W close · Ctrl+Tab cycle · Ctrl+Shift+T reopen
  • Find in page — toolbar Enter or Ctrl+F
  • Favorites — star sites; drag-reorder; pinned under Favorites in Browse
  • Keep browser warm — optional hide without killing CEF (title-bar collapse also keeps the helper alive)
  • Default landing site — Options picker; used by Home and when no tabs are saved
  • QuickAccess — Nexus icon at the top of the screen
  • Hotkey toggle — Ctrl+Shift+H (or K); rebind via Nexus
  • Branded homepage — how-to guide with logo + cover on first open
  • Cheat Sheets — offline pages (Raid Food, utilities, fractals, boons, Uber’s waypoints, dailies, and more) with interactive checklists
  • Live panels — Vault dailies, news digest, fashion wishlist, TP prices/craft costs, legendaries & characters (read-only API; optional key in Options)
  • Notes — local clipboard helpers for waypoints, chat codes, builds, and LFG snippets
  • Item Lookup — chat code / ID / name → rarity, prices, wiki & BLTC
  • Wallet & Stash — searchable wallet, materials, bank, and per-toon bags (API key)
  • Vault — free-floating Dailies & Wizard’s Vault with UTC reset countdowns (API key optional)
  • Copy URL and Open Ext — open Discord invites / Google login in your system browser
  • Single DLL — helper exe + homepage assets embedded; extracted on first use
  • No memory reads — official Nexus APIs only; safe with multiple GW2 clients (PID-scoped IPC)
  • Windows / Wine / Proton — works on Linux Steam as well as Windows

How to use

ActionDefault
Open / close helperCtrl+Shift+H (or K) or QuickAccess
New tab / site pickerCtrl+T or +
Close tabCtrl+W · x · middle-click
Cycle tabsCtrl+Tab / Ctrl+Shift+Tab
Reopen closed tabCtrl+Shift+T
Find in pageCtrl+F
Return skills to gameClick outside the helper window
  1. Open the helper — starts on the how-to Home page.
  2. Click Browse — search or pick a category, then a site.
  3. Click inside the page to interact; drag the title bar to move the window.
  4. Use Back, Forward, Home, and Reload as needed.
  5. Click outside the window (on the game) to return movement / skills to Guild Wars 2.
